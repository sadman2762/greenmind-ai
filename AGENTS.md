# Project development

- Frontend: `cd frontend`, `npm ci`, `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`. Both `http://localhost:5173` and `http://127.0.0.1:5173` work. Browser API requests default to same-origin; Vite forwards `/api` and the legacy `/traffic` endpoint to `http://127.0.0.1:8000` in dev and preview modes.
- All frontend API clients use `src/services/api.ts`. `VITE_API_BASE_URL` optionally specifies a backend origin (without `/api`); legacy `VITE_API_URL` is the fallback override. Cross-origin overrides require the backend to explicitly allow the frontend origin. Static production hosting must reverse-proxy `/api` and `/traffic` to the backend or provide an appropriate API origin at build time.
- Backend: create `backend/.venv` on macOS/Linux; the tracked `backend/Scripts` environment is Windows-specific. Install `backend/requirements.txt` plus `openai`, `python-dotenv`, `pytest`, and `httpx` into the virtual environment. These four imported/test dependencies are absent from the existing requirements file.
- Start the API from `backend` with `.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`.
- Verify frontend with `npm run build`. Full `npm run lint` has pre-existing failures in Copilot, context, and fleet pages; use targeted ESLint checks for changed files as well.
- Verify backend from `backend` with `.venv/bin/python -m pytest tests -q`.
- Browser intro tests: start both servers, then run `npm run test:intro` from `frontend`. Install Chromium with `npx playwright install chromium` first. `GREENMIND_BASE_URL` optionally selects another app origin; `PLAYWRIGHT_CHROMIUM_EXECUTABLE` optionally selects an existing Chromium binary. Test screenshots are generated under ignored `frontend/test-results`.
- Connectivity regression tests: `npm run test:api` from `frontend`, with both servers running. These test real dashboard telemetry and read-only API data from localhost and 127.0.0.1. `GREENMIND_PREVIEW_URL` adds a third origin (browser preview or Vite production preview). The same `PLAYWRIGHT_CHROMIUM_EXECUTABLE` override is supported.
- `/` is the introduction; `/dashboard` is the workspace overview. Other workspace routes remain unchanged. The top bar provides an intro replay link.
- The intro uses existing MUI components, a cinematic palette in `src/components/intro/flightTokens.ts`, and locally scoped motion/spacing tokens. It intentionally ignores the workspace theme. The public `@qlab/ui@2.0.6` package metadata does not match the documented design-system library; do not install it without verifying the intended package source.
- The current intro is an 11.5-second, full-screen green-city film: parting clouds, aerial Debrecen, Kassai campus, DEIK entrance blind spot, sensor installation, sixteen network connections, closing clouds, then the GreenMind AI logo. User requirement: no visible interface text except the final brand, and no timeline, chapters, captions, or HUD. The user explicitly requested an exception for architectural “DEIK” lettering on the building’s front glass. Use icon-only accessible controls; keep the illustration/fidelity disclosure in accessible descriptions and source metadata rather than visible captions.
- `src/components/intro/campusGeography.ts` anchors the target to the university's published entrance coordinates (47°32.543′ N, 21°38.385′ E). Campus plan and architectural references are recorded there. The Kassai model in `kassaiCampus.ts` follows the user-supplied Screenshot 2026-09-21 at 2.19.37.png: rectangular DEIK courtyard/front glass, large oval courtyard block, vaulted sports hall/courts, circular auditorium/modern complex, orange-roofed historical buildings, landscaping and parking. The pink map selection tint is not a façade color. Dimensions and hidden elevations remain estimated, not survey-accurate; the blind spot and sensor placement are fictional. The sixteen existing positions are a static snapshot of the project API, verified by browser tests, not a live status feed.
- Maintain pause/replay, keyboard controls, reduced-motion static mode, WebGL fallback, and GPU/audio cleanup. The renderer stops at rest and pauses on hidden tabs. Web Audio sound is enabled by default but only starts on the play gesture; it must stop on pause, mute, fallback, or navigation. Do not add backend requests to the intro.
- Storyboard screenshot tests use Playwright's paused clock plus `fastForward` to capture exact phases without introducing a visible timeline or production-only test hooks.
- The user chose the realism upgrade without external services or paid map data. Keep all new scene assets generated locally; do not claim photogrammetric fidelity. `volumetricClouds.ts` ray-marches a local 3D density texture at capped resolution. `realisticMaterials.ts` owns procedural surface/foliage textures. Keep their GPU resources disposed with the scene.
- The renderer uses adaptive near/far planes (not logarithmic depth) so screen-space ambient occlusion can reconstruct depth correctly. AO runs only for campus/ground shots at reduced resolution; clouds skip rendering when fully open. Assign render-target textures to ShaderPass uniforms after construction, since uniform cloning cannot clone render-target textures.
